# svg-figure

도형 한 장을 **자기완결 SVG 파일 하나**로 그리는 절차.

산출물은 `<name>.svg` 하나다. HTML 래퍼를 만들지 않는다 — 브라우저가 `.svg`를
직접 열고, Confluence에는 파일 내용을 HTML 매크로에 통째로 붙여넣으면 되고,
이미지 첨부가 필요하면 같은 파일을 그대로 첨부한다. 한 파일이 세 용도를 덮는다.

**형제 스킬과의 경계** — 도형이 문서 안의 한 요소면 `html-doc`, 도형이 산출물
전부면 여기다. 문서를 요청받았는데 그 안에 다이어그램이 들어가는 것뿐이면
`html-doc`으로 넘긴다.

## 철칙

1. **자기완결.** 외부 리소스 참조 0 — 원격 이미지, 웹폰트(`@font-face`),
   `@import`, 외부 `href` 전부 금지. 그림이 필요하면 `data:` URI.
2. **JS 0.** `<script>`도, `onclick` 같은 이벤트 속성도 넣지 않는다. Confluence
   새니타이저가 어차피 벗기고, 벗기는 과정에서 주변 마크업이 깨진다.
3. **라이트 고정.** 다크 테마를 넣지 않는다. 대신 **배경 rect를 명시적으로
   깐다** — 투명 배경이면 Confluence 다크 모드에서 도형이 사라진다.
4. **id는 전부 파일 고유 접두사를 단다.** Confluence 한 페이지에 도형이 둘
   이상 붙으면 `id="arrow"` 같은 이름이 충돌해 화살촉이 엉뚱한 도형을 가리킨다.
   접두사는 파일 basename에서 딴다: `chat-flow.svg` → `id="chat-flow-arrow"`.
5. **스타일은 SVG 안에서만, 스코프해서.** HTML 매크로 안의 `<style>`은 **페이지
   전역으로 샌다**. `<style>`을 쓸 거면 반드시 루트 id로 스코프하고
   (`#chat-flow .box { … }`), 아니면 presentation 속성(`fill=` `stroke=`)만 쓴다.
   클래스 이름만으로 셀렉터를 쓰지 않는다.
6. **좌표는 격자에 스냅한다.** 4px 배수(8 권장). 임의의 소수 좌표가 나오면
   그건 계산을 하고 있다는 뜻이고, 계산은 깨진다 — [grid.md](grid.md)의 상수를
   쓴다.
7. **텍스트 폭을 계산하지 않는다.** [grid.md](grid.md)의 **글자 수 상한표**를
   보고, 넘으면 `tspan`으로 두 줄로 나눈다. 폭 계산은 하지 않는다.
8. **색은 팔레트에서만.** [grid.md](grid.md) 팔레트 값 그대로. 투명도가 필요하면
   `rgba()`가 아니라 `fill-opacity`를 쓴다.

## 절차

1. **패턴을 고른다.**

   | 그릴 것 | 템플릿 |
   | --- | --- |
   | 두 주체 이상의 시간순 왕복 (요청/응답) | [templates/sequence.svg](templates/sequence.svg) |
   | 분기·판단이 있는 처리 흐름 (위→아래) | [templates/flow.svg](templates/flow.svg) |
   | 계층·그룹에 담긴 컴포넌트와 연결 | [templates/arch.svg](templates/arch.svg) |

   셋 다 안 맞으면 `arch.svg`를 뼈대로 삼는다 — 박스와 선이 제일 자유롭다.

2. **템플릿을 출력 경로로 복사**하고, 루트 `id`·접두사를 파일 이름에 맞춰 전부
   바꾼다. `{{...}}` 자리를 실제 내용으로 채운다. 행·열을 늘리려면 grid.md의
   pitch 상수를 더해 좌표를 만든다 — 나눗셈이 나오면 잘못 가고 있는 것이다.

3. **검증한다 (필수):**

   ```bash
   node "<이 스킬 폴더>/check-svg.mjs" <출력.svg>
   ```

   exit 0이 될 때까지 고친다.

4. **눈으로 확인한다 (필수).** 정적 검사는 겹침 일부와 줄바꿈을 못 잡는다.
   PNG로 뽑아 실제로 본다:

   ```bash
   rsvg-convert -z 2 -o /tmp/fig.png <출력.svg>   # 또는
   google-chrome --headless --screenshot=/tmp/fig.png --window-size=1920,1200 <출력.svg>
   ```

   그리고 그 PNG를 **읽어서 확인한다** — 글자가 박스를 넘지 않는지, 선이 박스를
   가로지르지 않는지, 화살촉이 붙어 있는지. 문제가 있으면 좌표를 고치고 3번으로
   돌아간다.

5. **결과를 보고하고 붙이는 법을 안내한다** (아래 절).

## Confluence에 붙이기

사내 Confluence는 HTML 매크로가 열려 있다(Server/DC).

1. 페이지 편집 → `{html}` 매크로 삽입
2. `.svg` 파일 내용을 **통째로** 붙여넣기 (`<svg …>`부터 `</svg>`까지)
3. 저장

매크로가 막혀 있는 페이지라면 같은 파일을 **첨부**하고 이미지로 넣는다 — SVG는
첨부해도 렌더된다. 그래도 안 되면 4번 절차의 PNG를 첨부한다.

## 한계

- `check-svg.mjs`는 정적 검사다. 텍스트 폭은 글자 수 기반 **추정**이라 완벽하지
  않고, `path`로 그린 도형의 겹침은 보지 않는다. 4번 육안 확인을 건너뛰지 않는다.
- Confluence 매크로에서의 실제 렌더는 사내 환경에서만 확인 가능하다.
- 도형이 `viewBox` 960 폭을 넘어가면 잘게 쪼개는 걸 먼저 고려한다 — 한 장에 다
  넣으려고 폰트를 줄이면 붙였을 때 못 읽는다.
