새로 생기는 것

  1. 템플릿 목록 GET /templates(가칭). 항목 = 이름 · 첫 줄 · 최근에 쓴 때. 사용자가 지시한 기능이다(예시 값).

장면과 예시 값

8 안 모두 같은 장면 · 같은 값으로 그렸다. 노란 원 숫자는 S1 에서 S2 로 가는 손동작 순서다. 노란 테는 S1 에서 손이 닿는 자리, S2 에서 바뀐 자리다.

S1

S2

지금 화면

새 메모는 빈 본문으로 열린다. 값은 src/notes/EmptyEditor.tsx 12 줄에서 온다(예시 앱이라 지은 자리다).

1

본문 자리의 카드 격자

새 메모의 빈 본문 자리에 템플릿 카드 넷을 놓는다. 치기 시작하면 카드가 걷힌다.

레퍼런스Notion · 템플릿으로 시작 — 빈 페이지 아래에 템플릿 고르기가 선다.

2

새 메모가 여는 명령 팔레트

새 메모를 누르면 팔레트가 열린다. 템플릿 이름을 치고 Enter 로 고른다. Esc 는 빈 메모다.

3

오른쪽 템플릿 패널

편집기 오른쪽에 템플릿 패널을 연다. 카드를 눌러 미리 보고 '적용' 으로 넣는다.
