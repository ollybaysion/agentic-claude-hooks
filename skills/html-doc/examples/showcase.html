01

문서 골격

masthead(eyebrow → h1+영문 부제 → standfirst → credits → 개정 로그) 아래에 정적 rail과 본문 컬럼이 온다. 이 문단이 .lede — 섹션 도입 요지다.

본문 산문은 --measure(34rem) 폭을 지킨다. 식별자와 경로는 core/check.mjs처럼 칩으로, 외부 참조는 일반 링크로 쓴다 — 내비게이션은 self-contained 규칙에 안 걸린다. rail의 링크와 section id는 손으로 맞추며, check가 rail-anchor로 검증한다.

  • 이 문서엔 JS가 한 줄도 없다 — 테마 전환도 CSS 캐스케이드만으로 동작한다.
  • 인쇄하면 rail이 사라지고 본문이 전체 폭을 쓴다 (@media print).

03

목록 두 가지 — 순서의 유무

steps — 실제 순서가 있을 때만

  1. template.html 복사출력 경로로 복사하고 CONTENT 마커 안을 교체한다.
  2. 내용 채우기rail 링크·section id를 맞추고 인벤토리 스니펫을 조립한다.
  3. check.mjs 검증exit 0이 될 때까지 — 통과 전엔 완성이 아니다.

rules — 순서 없는 규칙 묶음 (마크 = 실제 식별자)

  • ◆
    토큰만 쓴다 check 강제 인라인 style의 색 리터럴은 inline-color가 반려한다.
  • ◆
    모노 라벨은 정보일 때만 장식용 넘버링·라벨은 넣지 않는다 — 번호는 순서가, 라벨은 분류가 실재할 때.
