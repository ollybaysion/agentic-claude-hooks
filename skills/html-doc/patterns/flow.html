플로우 패턴

파이프라인·수집 경로·처리 단계를 왼쪽에서 오른쪽으로 흐르는 모노스페이스 노드 행으로 그린다. 좌표 계산이 없는 순수 마크업 — v1의 architecture 패턴(존·층)을 흡수한 후계다.

01

언제 쓰나

단계·경로·파이프라인 — 데이터가 순서대로 흘러가는 구조. 입력/출력의 묶음은 branch로 세로 분기한다. 되돌아가는 루프 하나까지는 arrow.back(블루 ↺)으로 표현할 수 있다.

안 되는 것: 자유 배치 박스 사이를 대각선·우회 엣지가 잇는 임의 그래프. 그건 pre.diagram(ASCII)으로 후퇴하거나 구조를 단계형으로 다시 정리한다 — 엣지가 얽히는 그림은 대개 설계가 덜 정리됐다는 신호다.

노드 의미색: 기본 = 내부 컴포넌트 · io = 외부 입출력(점선) · lead = 주인공(테라코타) · gate = 관문/검증(블루). 색이 의미를 가지면 본문에 범례를 먼저 선언한다.

02

데모 — 커버리지 파이프라인

session.jsonl subagents/*.jsonl → extract → expose → metrics → CLI report dashboard

코어는 순수 함수 — 입력(점선)과 소비자(블루) 사이에서 산출물은 JSON 하나

03

사용법 (모델용 절차)

  1. CSS 블록을 문서 <style> 끝에 복사한다. 색은 전부 토큰 참조라 추가로 지킬 것이 없다.
  2. 마크업 블록을 복사해 교체한다. 흐름은 왼→오른쪽 하나, 갈라짐/모임은 branch, 되돌이는 arrow.back 하나까지만.
  3. 다이어그램 내부에 h2/h3 금지 — 라벨은 노드 텍스트와 caption으로. lead는 다이어그램당 1~2개만.
  4. 렌더 후 check.mjs는 평소대로.
