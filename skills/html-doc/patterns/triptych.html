triptych 패턴

1px 괘선으로 이어붙인 3열 카드 그리드. 두 용법 — ① 대안 3안 검토(채택안 pick 강조), ② 리포트 머리의 대표 수치 타일(h4.num). v1의 compare(3안)·stats 패턴을 흡수한 후계다.

01

언제 쓰나

대안 검토: 옵션 3개를 나란히 — zone 라벨로 지위(기본값/옵션/ 대안)를 표시하고 채택안에만 pick. 결정과 근거는 카드 밖 .decision 콜아웃에 날짜와 함께 적는다. 2안이면 versus, 4안 이상이면 표가 낫다.

수치 타일: 리포트 머리에 대표 수치 3개(46rem 미만에선 세로 스택). 수치는 h4.num, 라벨은 zone, 해석 한 줄은 p — 수치 자체에 색을 칠하지 않는다. 6개를 넘으면 표로.

02

데모 ① — 대안 3안 검토

옵션 A

scope — 사용자 지정 범위

  • 감사 용도에 정확
  • 세션마다 사람이 지정해야 — 자동 집계 불가
기본값 B

edit-derived — 자동 유도

  • 완전 자동 — 대시보드 집계의 전제
  • 편집 없는 세션엔 fallback 필요
옵션 C

golden — 명시적 목록

  • 연구·회귀에 정확
  • 목록 작성 비용 — 일상엔 비현실적
03

04

사용법 (모델용 절차)

  1. CSS 블록을 문서 <style> 끝에 복사한다.
  2. 대안 검토: pick은 채택안 하나에만, 나머지 zone은 alt(회색). 결정 기록은 카드 밖 .decision으로.
  3. 수치 타일: 수치 출처(측정 시점·기간)를 섹션 제목이나 본문에 남긴다.
  4. 렌더 후 check.mjs는 평소대로.
