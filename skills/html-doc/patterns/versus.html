언제 쓰나

정확히 두 대상을 맞세울 때 쓴다. 두 전략, 두 실패 모드, 옛 방식과 새 방식.

카드 두 장이 같은 뼈대(tag → h3 → 설명 → dl)를 나눈다. 그래서 차이가 구조로 읽힌다. 셋은 triptych, 넷 이상은 표가 맡는다.

견본

전략 A · 다시 읽기

읽었던 파일을 다시 읽는다

패치 직전에 관련 파일을 다시 연다. 흐려진 맥락을 새로 채운다.

사용 하락
19.6 % — 가장 낮다
해석
다시 읽기는 손실을 막는 전략이다
전략 B · 한 번 읽기

한 번 읽고 다시 열지 않는다

찾기는 성공한다. 쓸 때는 소화하지 못한 채 패치를 쓴다.

사용 하락
43.1 % — 찾은 것의 절반이 사라진다
해석
"적게 읽기 = 효율" 이 뒤집힌 자리다

쓰는 법

  1. CSS 블록(CSS:START ~ CSS:END)을 문서 <style> 끝에 붙인다.
  2. 마크업 블록을 복사해 내용을 바꾼다. 두 카드의 dl 라벨은 같은 순서로 둔다.
  3. 결론은 카드 밖, 아래 결정 카드(ol.dec)에 적는다.
  4. check.mjs 를 돌린다.
